Este repositorio solo contiene las **versiones publicadas** de TuneSnag (el instalador). No incluye el código fuente.

## Qué hace

- **Modo Canciones**: busca el audio oficial del álbum, sin intros ni escenas de video.
- **Vista previa ▶**: escucha la canción antes de descargarla.
- **MP3 en alta calidad**, con portada, artista y álbum en sus etiquetas, guardado como `Canción - Artista.mp3`.
- **Gratis y sin anuncios.**
- Se mantiene al día sola: actualiza su motor de descargas ([yt-dlp](https://github.com/yt-dlp/yt-dlp), de código abierto) para seguir funcionando cuando cambian las páginas de video.

## Requisitos

- Windows 10 u 11 de 64 bits.
- Conexión a internet. La primera vez que se abre, TuneSnag descarga sus herramientas (~160 MB, una sola vez).

## Instalación

1. Descarga **`TuneSnag-Setup.exe`** desde la [última versión](https://github.com/taylorgr93/tune-snag-releases/releases/latest).
2. Ábrelo. Si Windows muestra **"Windows protegió su PC"**, haz clic en **Más información → Ejecutar de todas formas**. Aparece porque el instalador todavía no tiene firma digital; no significa que tenga un virus.
3. Sigue los pasos. No se necesita contraseña de administrador.

Para desinstalar: **Configuración → Aplicaciones → Aplicaciones instaladas → TuneSnag → Desinstalar**. Tus canciones descargadas no se borran.

## ¿Encontraste un problema?

Abre un [issue](https://github.com/taylorgr93/tune-snag-releases/issues) y, si puedes, adjunta el archivo de registro: `%LOCALAPPDATA%\TuneSnag\logs\tunesnag.log`.
